# Quick start

1. Open the Arc Mainnet version of the AchSwap app and connect a compatible EVM wallet. Verify the app is using chain ID 5042 before signing.
2. Switch the wallet to **Arc Mainnet (5042)**. See [network setup](/getting-started/network-setup).
3. Keep some USDC for gas and select the tokens you want to swap.
4. Enter an amount, then review the quoted output, price impact, minimum received, and route.
5. Approve a token if the selected route requires an ERC-20 allowance, then confirm the swap in your wallet.

The swap screen compares AchSwap's own router, LI.FI and KyberSwap, and shows the best output after fees. A quote is an estimate until the transaction executes. If no route appears, try a smaller amount or check whether that token pair has liquidity.

To provide liquidity instead, choose an [AchSwap V2 or V3 pool](/achswap/add-liquidity).
