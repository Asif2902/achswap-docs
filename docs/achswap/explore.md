# Explore tokens

The **Explore** page lists tokens trading on Arc, ranked by trading volume, with their market data:

| Column | Meaning |
| --- | --- |
| **Price** | The latest price in USD. |
| **24h %** | The price change over the last 24 hours. |
| **24h Volume** | The value traded across Arc DEXs in the last 24 hours. |
| **Market Cap** | Price × circulating supply, as reported for the token. |
| **Liquidity** | The value held in the token's pools. Shown on wide screens. |

Market data comes from [DEX Screener](https://dexscreener.com) and covers trading across Arc, not only on AchSwap. It refreshes every few minutes.

## Search

Type a name, symbol or contract address to search. Search also finds tokens outside the top list.

## Trade a token

Click a token to open the Swap page with USDC → that token already selected. A token you found by search is added to your token list in this browser.

## A listing is not an endorsement

Anyone can create a token on Arc and give it any name, including the name of a well-known asset. Before you buy:

- **Check the contract address** against the project's official channels.
- **Look at liquidity.** A token with little liquidity can be hard to sell, and its price can move a lot on small trades.
- **Watch for warnings on the Swap page.** The app flags unverified tokens, and warns when no provider can sell a token back, which can mean it can only be sold where it was launched, or not at all.

AchSwap's router does not route tokens with transfer taxes or transfer restrictions. See [smart routing](/achswap/smart-routing).
